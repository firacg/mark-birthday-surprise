# С днём рождения, Марк! 🎉

Праздничный мини-сайт: видеопоздравление, конфетти, искорки, повторный просмотр, управление звуком и полноэкранный режим.

GitHub Pages публикуется из корня ветки main. Рабочий адрес после включения Pages: https://firacg.github.io/mark-birthday-surprise/

## Текущий ролик
Версия 1015, длительность около 18,4 секунды. Для быстрой загрузки подготовлена копия H.264/AAC 1920×1080 с faststart. Исходный ролик не изменяется.

## Обновить видео
Положить новый MP4 и постер в assets, изменить соответствующие пути в index.html и отправить коммит в main. При этом адрес GitHub Pages останется прежним.
Локальный помощник: python tools/prepare-media.py путь-к-видео.mp4 (нужен imageio-ffmpeg). Он создаёт файлы greeting-1015.mp4 и poster-1015.jpg; при следующих версиях лучше использовать новое имя для сброса кеша браузера.

## Локальный просмотр
python -m http.server 4173

Простой статический HTML/CSS/JS, без сборки, сторонних библиотек и аналитики.
Если браузер разрешает, видео пытается запуститься со звуком при открытии. Иначе воспроизведение начинается по большой кнопке. Анимация учитывает prefers-reduced-motion.
